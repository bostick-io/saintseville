Sources

Approved Sources

Saint Seville is an approved sources only system. It answers from the documents listed here and does not search the open web. The categories below describe the approved corpus. A few real, verified links are shown as examples. The full corpus is versioned and grows over time under Paul's review.

Honest note: this is a closed, reviewed set of sources. If a document is not on the approved list, Saint Seville will not use it. That is by design, so answers stay tied to primary Church texts.
